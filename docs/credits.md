## Where it comes from

Moroder began as **[orrnithogalum/moroder](https://github.com/orrnithogalum/moroder)**, a YouTube Music client for the Linux terminal. Its idea, its C++ core and its look are the ground this project is built on. Thank you for writing it and for publishing it as free software.

This repository has since become its own project. It runs on macOS, Linux and Windows, and has its own installers, releases and features (Explore, synced lyrics, the Library, menus, gapless playback and more). It is developed independently: it is not affiliated with, reviewed or endorsed by the original project, and its bugs are its own. Fixes that concern the original code are offered back upstream.

Both are released under the [GNU AGPL v3](../LICENSE), and the original copyright notices are kept.
